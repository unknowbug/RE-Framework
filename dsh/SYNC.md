## 同步规则（维护者必读）

1. **技能正文改动**：直接发生在 `dsh/skills/`（DSH 技能**单一事实源**；Reasonix 镜像已于 2026-08-21 归档至 `archive/reasonix/`）。改后确认 `python dsh/tests/test_manifest.py` 通过，并更新本文件差异记录。
2. **frontmatter 适配改动**：直接改 `dsh/skills/<name>/SKILL.md` 的 frontmatter（kebab 名 + `whenToUse`），并在此文件登记变更。
3. **框架语义更新**：先改 `../spec/engineering-framework-v1.md`，再同步技能正文与 DSH 适配；Anchorlaw 引用版本核对用 `git grep 'v0\.[0-9]'`（当前基线 v0.24）。
4. **上游 DSH 漂移**：harness 改名/移除插件包时，`pwsh dsh/scripts/selfcheck.ps1` 第 [5] 项（`tests/audit_preset_rows.mjs`）会 fail-closed 拦下；harness 删改**提示词变量**（persona 模板渲染期严格解析）时，第 [6] 项（`tests/audit_prompt_variables.mjs`）会 fail-closed 拦下。修复 = 改 **`dsh/cordis.patch.yml`**（preset 的 ACTIVE carrier，DSH >= 0.1.7）跟上游 + 重跑 `install.ps1` + 登记本文件。**harness 每次升级后先读上游 `docs/upgrade-guide/<版本>/`**——本次事故（`{{cwd}}` 被删）在该指南 §Migration 里有明文条目。
5. **新增技能**：在 `tests/test_manifest.py` EXPECTED 中登记（DSH-only 技能登记进 DSH_ONLY）；`install.ps1` 按目录自动同步。
